## 형식과 처리 결정

`{source_base, template}`는 테스트 실행기 전용 래퍼다. 저장되는 template@2에는 원본 경로가 남지 않는다. 자동 배열 엔진은 기대값 파일을 읽지 않는다. 새 프로젝트는 project@1의 빈 texts/placements에서 시작하며, PDF 생성·글꼴·비변형 처리는 기존 3-1차 코드를 사용한다.

기존 배정의 파일 대상은 유지하면서 출력 위치 기준 상대경로 문자열만 다시 계산한다(§2.1, TASK-03-1 §3.4). 끝에 도달한 경고의 `blocked_cell`은 null이고, 미배정 파일 목록은 정렬 순서다. 리포트의 파일 목록은 절대경로, 추가 배정의 file은 출력 프로젝트 기준 상대경로다.

3-1차 코드 결함 수정은 없으며, 기존 CLI에 자동 배열 명령만 추가했다. 문서와 다르게 처리한 기능이나 미해결 요구사항 질문은 없다.
