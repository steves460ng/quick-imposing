참가자, 기간, 종료 기준은 사용자가 정한다. 아래에 제안값을 적었고, 정해지면 이 문서를 고친다.

---

## 1. 목적

자동 검증으로는 볼 수 없는 것을 실제 작업 환경에서 확인한다.

1. 실무자가 설명서만 보고 템플릿을 만들고 판을 저장할 수 있는가.
2. 저장한 PDF가 인쇄 공정(Illustrator 확인, 출력)에서 문제없이 쓰이는가.
3. 임의로 정한 화면 · 동작(`docs/UI-DESIGN.md` §6)이 실무에 맞는가.

## 2. 범위

| 구분 | 내용 |
|---|---|
| 포함 | 템플릿 편집기, 작업 프로그램, 사용설명서, 배포 폴더 설치 · 교체 |
| 제외 | 명령행 도구, 설치 프로그램, exe 서명, 회사 밖 배포 |
| 실제 인쇄 | 베타 PDF로 실제 인쇄를 할지는 사용자가 정한다. 하기 전에 4절 S7(Illustrator 확인)을 먼저 통과시킨다 |

## 3. 참가와 기간

| 항목 | 값 |
|---|---|
| 참가자 | (미정) 제안: 평소 쿽으로 임포징을 하는 실무자 1~2명 + 임포징 경험이 없는 실무자 1명 |
| 기간 | (미정) 제안: 1~2주, 실제 작업 5건 이상 |
| 연락 창구 | (미정) 문제를 모아 전달할 사람 |

**배포**: `docs/HANDOFF-2026-11-13.md`의 업데이트 절차대로 빌드해 zip을 전달한다. 참가자 PC에는 템플릿이 없으므로, 템플릿을 미리 만들어 함께 주거나(템플릿 폴더 복사) S1부터 직접 만들게 한다. 어느 쪽인지에 따라 확인되는 것이 다르다. 실무자가 템플릿을 만들 일이 없다면 미리 만들어 주는 쪽이 실제에 가깝다.

## 4. 확인 시나리오

참가자마다 해 본 것에 표시한다. 막힌 곳과 헷갈린 곳이 가장 중요한 결과다.

| # | 시나리오 | 볼 것 |
|---|---|---|
| S1 | 편집기로 실제 사양의 템플릿 만들기 (전면) | 셀 크기 · 시작 위치 · 피치 입력이 헷갈리지 않는가. 미리보기가 기대한 배열인가 |
| S2 | 전면 템플릿을 복제해 후면 템플릿 만들기 | 베이스 바꾸기가 자연스러운가 |
| S3 | 텍스트 항목 추가 (제품명, 날짜 등), 글꼴 고르기 | 위치 잡기가 쉬운가. 필요한 글꼴이 목록에 있는가 |
| S4 | 작업 프로그램에서 파일 여러 개를 한 번에 넣기 | 파일 이름 순서가 기대와 같은가 (1, 2, … 10, 11) |
| S5 | 일부 셀만 채우기, 데이터 바꾸기, 셀 비우기 | 자동 배열이 막혔을 때 안내를 이해하는가 |
| S6 | PDF 저장, 같은 이름으로 다시 저장 | 4개 파일이 생기는가. `이름-2` 제안이 불편한가 |
| S7 | **저장한 PDF를 Illustrator로 열기** | 카드가 모두 보이는가. 방향, 위치, 글자가 맞는가 (SPEC V15 · V18) |
| S8 | 저장해 둔 프로젝트를 다시 열어 고친 뒤 저장 | 빠진 데이터 채우기가 되는가 |
| S9 | 한글 폴더, 다른 드라이브(USB, 네트워크 폴더)의 B 데이터로 작업 | 저장이 되는가. 안 될 때 안내를 이해하는가 |
| S10 | 실제 작업 1건을 처음부터 끝까지, 쿽으로 할 때와 비교 | 걸린 시간, 빠진 기능 |

## 5. 문제 보고

아래 내용을 연락 창구로 보낸다. 화면 캡처가 있으면 가장 빠르다.

```
버전: (프로그램 폴더의 VERSION.txt)
프로그램: 작업 프로그램 / 템플릿 편집기
하려던 일:
한 순서:
기대한 결과:
실제 결과:
첨부: 화면 캡처, 해당 .qiproj.json, .report.json
```

저장이 실패했거나 PDF가 이상하면 같은 폴더의 `.qiproj.json`과 `.report.json`을 함께 보낸다. 템플릿 문제면 템플릿 폴더(`도구 → 템플릿 폴더 열기`)의 해당 폴더를 보낸다.

**심각도**

| 등급 | 기준 | 처리 |
|---|---|---|
| A | PDF가 잘못 만들어짐(위치 · 방향 · 누락 · 변형), 저장 불가, 프로그램이 죽음 | 즉시 수정하고 새 빌드 배포 |
| B | 작업은 되지만 돌아가야 함, 안내를 이해할 수 없음 | 베타 기간 안에 수정 |
| C | 불편, 모양, 있으면 좋은 기능 | 모아서 베타 뒤에 판단 |

## 6. 종료 기준 (제안)

- A등급 문제가 없다.
- S7(Illustrator 확인)을 실제 사양의 판으로 통과했다.
- 참가자가 설명서만으로 S4~S6을 끝냈다.
- `docs/UI-DESIGN.md` §6의 6개 항목을 확정했다.

## 7. 알려진 제한

베타 시작 시점에 이미 알고 있는 것이다. 보고하지 않아도 된다.

| 제한 | 설명 |
|---|---|
| 같은 이름 덮어쓰기 불가 | 결과 파일이 이미 있으면 `이름-2`로 저장한다 |
| 다른 드라이브 | B 데이터와 저장 위치는 같은 드라이브여야 한다 |
| 템플릿 이름 변경 불가 | 저장한 뒤에는 이름을 바꿀 수 없다. 복제해서 새 이름을 쓴다 |
| 첫 실행 경고 | 서명되지 않은 exe라 Windows가 경고할 수 있다 (`추가 정보 → 실행`) |
| 템플릿 위치 | PC 사용자마다 따로 저장된다. PC 사이에 자동으로 공유되지 않는다 |
| 셀 개별 편집 불가 | 셀을 하나씩 옮기거나 지울 수 없다 (요구사항상 범위 밖) |
| 재단선 없음 | 재단선을 넣지 않는다 (요구사항상 범위 밖) |
