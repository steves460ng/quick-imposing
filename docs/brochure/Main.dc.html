사원증 · 명함 등 카드형 인쇄물

템플릿 기반
카드 제판 도구

판형(셀 배열, 카드 회전, 텍스트 위치)을 템플릿으로 정의해 두고, 카드 PDF를 배치해 인쇄용 판 PDF를 생성합니다. 원본 데이터는 변형하지 않고 회전과 위치 이동만 적용합니다.

적용 사례 · 주문 수량별 제판 시간

선은 경향을 나타낸 개념도이며, 수치는 사원증 400명 이상 주문 1건의 사내 작업 실적입니다.

01

학습 부담이 적은 작업 흐름

템플릿 선택, 데이터 입력, PDF 저장의 세 단계로 작업합니다. QuarkXPress와 달리 판 구조를 매번 다루지 않아 처음 쓰는 사람도 바로 작업할 수 있습니다.

02

템플릿으로 규격 표준화

셀 크기, 간격, 회전, 글자 자리를 템플릿 편집기로 미리 정해 두고 다시 씁니다. 누가 작업해도 같은 판이 나오고, 용지나 주의 사항은 메모로 함께 남습니다.

03

대량 배치 자동화

파일을 여러 개 고르면 이름 순서대로 칸을 채웁니다. 같은 카드는 셀 복사와 연속 붙여넣기로 한 번에 늘립니다.

추가 예정 폴더를 끌어다 놓으면 폴더 안의 PDF를 이름 순서대로, 이미 채운 카드 다음 칸부터 이어 채웁니다.
