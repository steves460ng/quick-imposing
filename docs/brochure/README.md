## 목표와 범위

퀵 임포징을 소개하는 2쪽 분량 브로셔. 사용자가 정한 강조점:

1. 쿽(QuarkXPress)보다 배우기 쉽다.
2. 템플릿 편집기로 판형을 미리 만들고 재사용해 표준 규격을 지키기 쉽다.
3. 사원증 대량 주문(400명 이상) 제판이 쿽으로 약 3시간, 퀵 임포징으로 약 30분(사용자 제공 수치, 사내 작업 기준).

스크린샷을 넣는다(사용자 요청).

- 2026-11-19: 제목이 "약장사 같다"는 사용자 의견으로 1쪽 제목을 바꿨다.

  - 지금: 머리말 "사원증 · 명함 등 카드형 인쇄물", 제목 "템플릿 기반 카드 제판 도구", 기술적인 소개 문장. 시간 수치는 "적용 사례 · 사원증 대량 주문(400명 이상) 제판 시간" 상자로 옮기고 "주문 1건 기준, 사내 작업 실적"으로 표기.
- 2026-11-19: 열린 질문 5개에 대한 사용자 답.
  1. 시간 수치의 측정 조건: 선호 없음. "주문 1건 기준, 사내 작업 실적" 그대로 둔다.

## 이어서 작업하는 법

- **캔버스를 고칠 때**: claude.ai Artifact 도구로 위 링크를 `read`하고(`project/canvas.json`, `project/Main.dc.html`, `project/Page2.dc.html`), 고친 파일만 같은 `url`로 publish한다. 캔버스가 원본이고 이 폴더는 사본이다. 페이지에서 사람이 직접 고쳤을 수 있으니 이 폴더가 아니라 캔버스에서 읽어 시작한다.
- **이 폴더 갱신**: 캔버스를 고친 뒤 같은 세 파일을 다시 복사해 커밋한다.
- **이미지**: 두 스크린샷은 캔버스에 업로드한 자산이다.

  | 파일(이 저장소) | 캔버스 자산 주소 | 쓰는 곳 |
  |---|---|---|
  | `docs/images/editor.png` | `/_blob/b1e609fb78558863838defcb9db896bc` | 2쪽 STEP 1 |
  | `docs/images/work.png` | `/_blob/0cebdc96f6fa409e3c1076dbe2bcfda4` | 2쪽 STEP 2 |

  `.dc.html` 안의 `/_blob/…` 주소는 그 캔버스 안에서만 열린다. 새 캔버스를 만들면 이미지를 다시 업로드하고 주소를 바꿔야 한다.
- **스크린샷 다시 만들기**: README 화면 그림과 같은 방식(Qt offscreen으로 `EditorWindow` · `WorkWindow`를 띄워 `grab()`). 예시 템플릿 이름 `명함-전면`, 메모, 2번 셀 보정, 상태 표시줄에는 기본 템플릿 폴더 경로를 넣었다.
